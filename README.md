    Lesson 1: What is conditional probability?
        `In Stage 1, we learned:
        \[
        P(A)=\frac{\text{Favourable outcomes}}{\text{Total outcomes}}
        \]
`
    This works when all the outcomes in our sample space are equally likely.

    Now imagine that someone gives us additional information before we calculate the probability.

    That information may reduce the number of possible outcomes.

    Conditional probability is the probability of an event happening, given that another event has already happened.
